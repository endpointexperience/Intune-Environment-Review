
# Enrollment

## Review goal

Review how devices are enrolled into Intune and verify that enrollment
methods, restrictions, and related configurations still match the
organization's requirements.

## Review checklist

- [ ] Review configured enrollment methods
- [ ] Review enrollment restrictions
- [ ] Review device platform restrictions
- [ ] Review device limit restrictions
- [ ] Review Windows Autopilot configuration
- [ ] Review Windows Autopilot profiles and assignments
- [ ] Review Enrollment Status Page configuration
- [ ] Review corporate device identifiers where applicable
- [ ] Review personally owned device enrollment strategy
- [ ] Review enrollment-related groups and assignments
- [ ] Identify enrollment configurations that are no longer used

## Questions to ask

- Which enrollment methods are currently in use?
- Are users allowed to enroll personally owned devices?
- Are platform restrictions intentional?
- Are enrollment restrictions still aligned with current requirements?
- Are Windows Autopilot profiles still required and correctly assigned?
- Does the Enrollment Status Page configuration reflect the current deployment process?
- Are old enrollment configurations still present?
- Is the enrollment process documented and understood by the administrators?

## Review outcome

### 🟢 Good

Enrollment methods and restrictions have a clear purpose and support the
organization's current device provisioning strategy.

### 🟡 Review

The configuration may be valid, but its purpose, assignments, or
documentation should be reviewed.

### 🔴 Action

The configuration creates an identified enrollment issue or requires
remediation.
