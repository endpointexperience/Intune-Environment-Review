# Contributing

Thanks for your interest in contributing to the Intune Environment Review project!

This project is intended to be a practical, community-driven resource for reviewing Microsoft Intune environments.

Contributions of all sizes are welcome.

## Ways to contribute

You can help by:

- Adding new review checks
- Improving existing checks
- Suggesting new review areas
- Adding relevant Microsoft documentation
- Improving explanations or wording
- Sharing real-world considerations that others may benefit from
- Reporting outdated or incorrect information

## Suggesting a new review check

When suggesting a new check, try to answer these questions:

1. What should be reviewed?
2. Why does it matter?
3. What question should an administrator ask?
4. Is there relevant Microsoft documentation?

The goal is not to define a single "correct" Intune configuration.

Different organizations have different requirements. Review checks should help administrators understand their environment and make informed decisions.

## Pull Requests

Pull requests are welcome.

When submitting a pull request:

- Keep changes focused on one topic when possible
- Explain what you are adding or changing
- Include links to relevant Microsoft documentation where appropriate
- Avoid presenting organizational preferences as universal best practices
- Keep the language practical and easy to understand

## Issues

Not ready to submit a pull request?

Open an issue instead.

Issues can be used to:

- Suggest a new review area
- Discuss an existing check
- Report outdated information
- Suggest an improvement
- Share an idea for the project

## Review philosophy

The checklist is built around three simple outcomes:

- 🟢 **Good** – The configuration has a clear purpose and works as intended.
- 🟡 **Review** – The configuration may be valid but deserves review or better documentation.
- 🔴 **Action** – The configuration requires attention or remediation.

The important question isn't only whether a setting exists.

**It's whether you can explain why it's configured that way.**

## Community

Please keep discussions constructive, respectful, and focused on helping the Microsoft Intune community.

Thank you for contributing!
